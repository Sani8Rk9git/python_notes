**WHAT IS STRING??**



\-> Python strings are characters enclosed in quotes of any type- single , double , triple

\-> An Empty string is a string that has 0 characters 

&#x09;-> represented as just a pair of quotation marks

\-> Python strings are immutable

\-> Each character in the string has a unique position / index

&#x09;-> In forward direction 0 to (length of string - 1)

&#x09;-> In backward direction -1 , -2 , ... -length 



\-> The str(<object>) constructor can be used to create strings from other objects

\-> While the str(<object>) constructor can be used to coerce/convert strings, it will not iterate or unpack an object.

&#x09;-> ex: numbers = \[1,2,3]

&#x09;-> str(numbers)

&#x09;-> '\[1,2,3]'



\-> Python has no character data type

\-> so indexing a string produces a new str of length 1:

&#x09;-> name = "python"

&#x09;-> type(name\[0])

&#x09;-> str
