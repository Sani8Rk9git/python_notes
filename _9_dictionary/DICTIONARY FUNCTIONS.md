**DICTIONARY FUNCTIONS**



\-> len(<dict>)

&#x09;-> return the count of the key:value pairs in the dictionary



\-> min(<dict>)

&#x09;-> work on keys of the dictionaries

&#x09;-> keys must be of homogeneous type

\-> max(<dict>)

&#x09;-> work on keys

\-> sum(<dict>)

&#x09;-> work on keys



\-> <dict>.items()

&#x09;-> returns a list of tuples of key,value pairs

\-> <dict>.keys()

\-> <dict>.values()



\-> <dict1>.update(<dict2>)

&#x09;-> the key value pairs of the <dict2> are added to the <dict1> and replace the keys in the <dict1> having the same key as <dict2>



\-> <dict>.setdefault(<key> , <value>)

&#x09;-> add the key value pair if the key does not exist

&#x09;	-> returns the value of the new key added

&#x09;-> if the key exists then the key value pair is not added

&#x09;	-> the current value associated to the key is returned

&#x09;-> if no value is given 

&#x09;	-> None is associated to the key, if added
