**CHECKING EXISTENCE OF KEY**



* The membership operators **in** and **not in** check for the existence of keys only.



Syntax:



<key> in <dictionary>

\-> return True if key is present but False if not present



<key> not in <dictionary>

\-> return True if key is not present but False if present







<value> in <dict\_name>.values()

\-> it can be used to search for the value in the dictionary
