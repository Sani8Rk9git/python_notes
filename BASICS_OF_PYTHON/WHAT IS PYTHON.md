**WHAT IS PYTHON??**



\-> Python is a dynamic and strongly typed programming language.

&#x09;-> dynamically typed : it means python determine the datatype of the variable at

&#x20;										runtime

&#x09;					(means during program execution)

&#x09;	-> we do not need to declare the datatype of the variables beforehand

&#x09;	-> the datatype associated with a variable can be determined and changed

&#x09;						during program execution

&#x09;-> strongly typed : it means that when incompatible datatypes are combined, we 

&#x09;	as a programmer has to explicitly perform the type conversion.



\-> Python employs both duck typing and gradual typing, via type hints.

&#x09;-> duck typing : It means that python care more about what the object can do 

&#x09;	-> it does not care what class/datatype the object belongs to 

&#x09;	-> Python work with objects based on their behaviour

&#x09;-> gradual typing : Python allows you to add type hints that provide info what is

&#x09;			the datatype of the object

&#x09;	-> Ex: Without type hints: def add(a, b):

&#x09;	-> Ex: With type hints: def add(a: int, b: int) -> int:



\-> Python also support 3 programming styles:

&#x09;-> Imperative Programming

&#x09;	-> sequential way of writing the program from top to bottom to tell the 

&#x09;			computer step by step what to do

&#x09;-> Declarative / Functional Programming

&#x09;	-> focus on what we want rather than explaining every step

&#x09;	-> using functions

&#x09;-> Object oriented Programming

&#x09;	-> can create classes and objects



\-> Everything in python is an object

&#x09;-> every value and entity in python is an object

&#x09;-> every object has an identity, a type and a value

&#x09;	-> identity : object's address in memory

&#x09;		-> is operator compares identity of objects

&#x09;		-> id() function returns identity of the object

&#x09;		-> remains fixed

&#x09;	-> type

&#x09;		-> determines the operations that the object supports

&#x09;		-> The type() function returns an object’s type 

&#x09;		-> an object’s type is also unchangeable.



&#x09;	-> value

&#x09;		-> Objects whose value can change are said to be mutable

&#x09;		-> objects whose value is unchangeable once they are created 

&#x09;				are called immutable





\-> Python puts a strong emphasis on code readability and uses significant indentation to denote function, method, and class definitions.
