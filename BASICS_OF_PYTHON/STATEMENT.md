**STATEMENT**



* It is a programming instruction that does something (some action takes place)
* A statement is **executed** by python



Ex :



print("Hello")

a = 12

* An statement may or may not produce a value



* Statements are the instructions given to the computer to perform any kind of action

&#x20; action : data movements , making decisions , repeating tasks



* Statements form the smallest executable unit within the python program.
* PYTHON statements are of 3 types :



&#x20;1. Empty statement



* Also called Null statement
* this statement does nothing
* In python empty statement is **pass** statement
* When python encounter pass statement it does nothing and move the next statement in the flow of control.





&#x20;2. Simple statement



* Any single executable statement is simple statement

Ex: print("Hlo")





&#x20;3. Compound statement



* it represent a group of statements executed as a unit
