**WHY NEED PROGRAM?**



* All computer actions are governed by IPO cycle.

&#x20; \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_|

&#x20;|

IPO = Input , Process , Output

\-> there is certain input , certain kind of processing and an Output



* Programs make IPO cycle happen

\-> If we want to transform an input(of any kind) into an output(of any kind) , we need processing

\-> A program is a set of instructions that govern the processing

\-> So a program form the base for processing
