**COMMENTS**



* any line that begin with the **#** symbol is a comment in python.

&#x09;-> These lines are ignored by python

&#x09;-> Only for code readability



* **Inline** comments are written between the lines of the python code.
* Full line comments are whole lines that are comments.





Docstrings

&#x09;-> These multi-line comments

&#x09;-> These are used for documentation.

&#x09;-> The first statement of a function body can optionally be a docstring

&#x09;-> concisely summarizes the function or object's purpose.

&#x09;-> docstrings are declared using triple double quotes (""") indented at the same level as the code block

&#x09;-> are returned by calling the special attribute .\_\_doc\_\_ on the function, method, or class name.

&#x09;	-> <function\_name>.\_\_doc\_\_
