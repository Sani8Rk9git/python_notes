**SEQUENCES**



&#x20;1. Strings



* string datatype holds **string data**(any number of valid characters into a set of quotation marks)



* string is a sequence of characters
* Each character can be individually accessed using its **index**
* Strings are stored as individual characters in contiguous location with **two-way** indexing for each location.



Ex:



0  1  2  3  4  5   forward indexing

P  y  t  h  o  n

\-6 -5 -4 -3 -2 -1  backward indexing



* To access each character :



&#x20;  <string\_name>\[index]



* length of the string can be determined by the  **len**(<string>)
* Strings are **immutable** so item assignment is not supported (we cannot change the individual letters of the string in place by assignment)
* We can assign to a string another string or an expression that returns a string by using the assignment.





&#x20;2. Lists



* A list in python represent a **list of comma-separated values** of any datatype between square brackets.
* It can be assigned to a variable
* Lists are **mutable** (can be changed) (we can change/add/delete elements of the list)
* The values are internally numbered from zero onwards





&#x20;3. Tuples



* These are lists that cannot be changed (are immutable)
* Tuples are represented as group of comma-separated values of any datatype within parentheses.
