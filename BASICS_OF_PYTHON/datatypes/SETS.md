**SETS**



* it can store multiple values 
* sets are created by specifying comma-separated values enclosed in curly brackets {}
* elements of sets are **unordered** and unindexed
* do not allow duplicate entries
* Sets **cannot contain mutable elements**

(So a list cannot be stored in a set)

* sets are **mutable** (we can add or remove items from it) by using built-in functions
