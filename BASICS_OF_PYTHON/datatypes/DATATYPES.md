**DATATYPES**



* Python provides a predefined set of datatypes for handling the data it uses.
* Data can be stored in any of these datatypes.
* Data can be of many types : character , integer , real , string , boolean



* Python provides 5 types of built-in core data types :



&#x20; -> Number -----> integers -----> boolean

&#x20;           -----> floating point

&#x20;           -----> complex

&#x20; -> Sets

&#x20; -> None

&#x20; -> Sequences -----> list

&#x20;              -----> string

&#x20;              -----> tuple

&#x20; -> Mappings -----> dictionary





* python datatypes strings, lists, tuples, dictionary are iterables
* An iterable is any python object that can return its members one at a time
