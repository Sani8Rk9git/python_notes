**LITERALS**



* Also referred to as constant values
* These are the data items that have a **fixed value**
* Python allows following literals :

&#x20;                          1. String literal

&#x20;                          2. Numeric literal

&#x20;                          3. Boolean literal

&#x20;                          4. Special literal None

&#x20;                          5. Literal collection



* Literal collections (lists and tuples)
* Boolean literals and the None are the built-in constants/literals in python.
