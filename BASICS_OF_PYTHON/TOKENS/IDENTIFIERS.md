* These refer to the User-defined names given to different parts of the program(variables, objects, classes , functions , lists...)



RULES FOR FORMING IDENTIFIERS IN PYTHON



1. It can contain letters, digits and underscore ( \_ )
2. The first character must be a letter or underscore
3. Python is **case-sensitive** (it treats upper and lower case characters differently.)
4. It must not be a keyword of python
