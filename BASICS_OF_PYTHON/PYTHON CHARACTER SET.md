**PYTHON CHARACTER SET**



* Character set is a **set of valid characters** that python can recognize.
* Python has the following character set :

&#x20;

&#x20; 1. Letters           ----->   A-Z , a-z

&#x20; 2. Digits            ----->   0-9

&#x20; 3. Special symbols   ----->   space + - \* / \*\* \\ () \[] {} // = != == < , > . ' "

&#x20;                               ''' ; : % ! \& # <= >= @ \_

&#x20; 4. Whitespaces       ----->   tabs \\t , newline \\n

&#x20; 5. Other characters  ----->   all ASCII and Unicode characters



* Every component of a python program (statements, expressions) is **created using the character set.**
