**OBJECT** 



* Everything is an object in python (data items, literal values, strings, numbers, datatypes , variables)
* Python is an object oriented language and it creates and treats everything as an object.
* Python calls every entity that store any value or any type of data as an object



* Every Python object has 3 key attributes associated to it:



&#x20;1. type of the object



* It determines the operations that can be performed on the object
* type() returns the type of the object





&#x20;2. value of the object



* It is the data-item contained in the object
* print() is used to display the value of the object







&#x20;3. id of an object



* It is the memory location of the object
* id() returns the id of the object



* The id of the variable is the same as the id of the value it is storing (except complex

&#x20;                                                                           numbers)
