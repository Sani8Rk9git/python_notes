**INSTANCE VARIABLES**



\-> it is a variable that has different values for different objects

&#x09;-> its value depend on the object

&#x09;-> it has different values for different objects in the memory at the same time.

&#x09;-> the variables that are created inside the constructor



\-> the normal variables in python has a single value in memory at a point of time



\-> instance variable is different for each object

\-> it is always defined in the constructor
