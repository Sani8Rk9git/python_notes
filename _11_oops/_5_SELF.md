\-> Important rule of OOP

&#x09;-> the members of the class (attributes and methods) are accessed only by the object

&#x09;	of that class



\-> the members of the same class cannot access each other 

\-> this is where self is used

&#x09;-> it allow the members of a class to access other members of the same class

&#x09;-> it is a reference to the current object of the class

&#x09;-> with self, we have the object of the class inside the class, so now the members 

&#x09;	of the class can talk to each other



\-> when the object is just created, the object is automatically passed to the constructors and methods
