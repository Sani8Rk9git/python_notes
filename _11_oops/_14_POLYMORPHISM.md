**POLYMORPHISM**



\-> polymorphism means the same thing behaves differently in different situations



\-> there are 3 main concepts in polymorphism

&#x09;-> Method overriding

&#x09;	-> when a child class inherit from a parent class, then if there is a method

&#x09;		with the same name in both the classes, then when the child class 

&#x09;		object call the method then the child class method overrides the 

&#x09;		parent class method and gets executed

&#x09;-> Method overloading

&#x09;	-> there are two or more methods with same name in the same class but they 

&#x09;		behave differently based on the input

&#x09;	-> in python it does not work

&#x09;	-> but we can use the default arguments to indirectly do the method 

&#x09;		overloading

&#x09;-> Operator overloading

&#x09;	-> the same operator behaves differently based on the types of the input

&#x09;	-> implemented with the dunder methods
