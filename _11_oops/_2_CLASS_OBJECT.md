**CLASS\_OBJECT**



\-> the built-in datatypes in python (int , float, bool , function , list, tuple, set, dictionary) are built-in classes in python.

&#x09;-> we create objects of these classes



\-> Class

&#x09;-> a class is a blueprint/set of rules that define the behaviour of objects

&#x09;-> In a class we can have

&#x09;	-> data/attribute/property

&#x09;		-> define the characteristics of the object

&#x09;	-> functions/behaviour

&#x09;		-> define what the object can do



\-> python has 2 types of classes

&#x09;-> built-in classes

&#x09;-> user-defined classes





\-> Object

&#x09;-> an object is an instance of the class

&#x09;-> object follow the rules defined in the class

&#x09;-> an object of a class can be passed as argument to a function

&#x09;	-> the object is passed as reference(memory address) to the function

&#x09;	-> an object can be created inside the function and returned

&#x09;-> the objects are mutable by default

&#x09;-> we can store multiple objects in a list, dictionary





\-> syntax to create object

&#x09;-> object\_name = class\_name()



&#x09;-> when we write class\_name(), an object is created in the memory at a memory address

&#x09;-> the object\_name is just a reference to the class object, it is not the object

&#x09;	itself

&#x09;-> so the variables are references to the objects

&#x09;-> the variable has the address of the object



\-> syntax to create class

&#x09;-> class <class\_name>:

&#x09;-> 	#code



\-> python variables and function names are written in Snake case

&#x09;-> snake case => all lowercase words separated by underscore \_



\-> python class name is written in pascal case

&#x09;-> pascal case => every word is capitalized (first letter of the word)

&#x09;-> words are joined together(more than one word)





\-> the object will access the data and the methods defined in the class as

&#x09;-> <object\_name>.method()

&#x09;-> <object\_name>.attribute



\-> we can also create class object inside the class

\-> we can create the attributes from outside the class using the objects
