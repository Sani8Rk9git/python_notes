**CONSTRUCTOR**



\-> a constructor is a special function created inside a class

\-> variables created inside the class are created in the constructor

\-> to use the variables, write

&#x09;-> self.<variable\_name>



\-> the constructor function is called automatically when an object is created for the class

\-> syntax:

&#x09;-> def \_\_init\_\_(self):

&#x09;	#code



\-> in the constructor, we write the configuration related code

&#x09;-> those task that needs to be done without involving users to perform that task



\-> cannot rename the constructor in python

\-> we cannot have multiple constructors in a single class





\-> non-parameterised constructor

&#x09;-> it does not expect any input arguments from the user 





\-> parameterised constructor

&#x09;-> it require input arguments from the user
