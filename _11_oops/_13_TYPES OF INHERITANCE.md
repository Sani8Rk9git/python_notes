**TYPES OF INHERITANCE**



\-> Single inheritance

&#x09;-> a single parent class

&#x09;-> a single child class

&#x09;-> child class inherit from the parent class



\-> multilevel inheritance

&#x09;-> child class inherit from parent and its parent (parent inherit from its parent)

&#x09;-> it forms a chain

&#x09;-> 



\-> hierarchical inheritance

&#x09;-> multiple children classes inherit from a single parent class



\-> Multiple inheritance

&#x09;-> a single child class inherit from multiple parent classes

&#x09;-> class A(B , C):

&#x09;-> now if both the parents have methods with the same name, that parent method is 

&#x09;	called whose name is written first in the () of the child class

&#x09;	-> this is also called method resolution order



\-> Hybrid inheritance

&#x09;-> it is a combination of various types of inheritance
