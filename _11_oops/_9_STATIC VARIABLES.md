**STATIC VARIABLES**



\-> it is a class variable

\-> it is shared by all the objects

\-> written outside the constructor, in the class

&#x09;-> var = value

\-> accessed in the class as

&#x09;-> <classname>.var



\-> we can make the static variable private also

&#x09;-> \_\_var = value



\-> can make getter and setter for the static variables also

&#x09;-> we do not need to take self as a parameter for it

&#x09;-> these methods are accessed using the class names



\-> the methods that belong to the class are called static methods or utility functions.

&#x09;-> can write @staticmethod on top of them
