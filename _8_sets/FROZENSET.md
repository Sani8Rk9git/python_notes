**FROZENSET**



\-> it is an immutable version of the python set object





\-> creating a frozen set

&#x09;-> <var> = frozenset(<sequence>)



\-> union, intersection, difference, symmetric difference all can be applied on the frozenset

&#x09;-> as they return a new frozenset



\-> 2D frozensets are possible

&#x09;-> <var> = frozenset(\[val1 , val2 , frozenset(\[val2, val2]) ])
