**SET OPERATIONS**



\-> adding item in the set

&#x09;-> <set>.add(<value>)

&#x09;	-> add the value in the  set

&#x09;	-> add one item at a time



&#x09;-> <set>.update(\[val1 , val2 , ...])

&#x09;	-> add multiple items in the set

&#x09;	-> takes the values in a list as argument 

&#x09;	-> add the values in the set



\-> deletion operation in set

&#x09;-> del <set>

&#x09;	-> delete the complete set object



&#x09;-> <set>.discard(<item>)

&#x09;	-> it delete the particular item from the set

&#x09;	-> if the item does not exist, no error is shown



&#x09;-> <set>.remove(<item>)

&#x09;	-> it delete the particular item

&#x09;	-> if the item does not exist, error is shown



&#x09;-> <set>.pop()

&#x09;	-> this will delete an item randomly from the set



&#x09;-> <set>.clear()

&#x09;	-> delete all the items and make the set empty





\-> union

&#x09;-> <set\_1> | <set\_2>

&#x09;-> all elements from both the sets one time appears



\-> intersection

&#x09;-> <set\_1> \& <set\_2>

&#x09;-> common elements from both the sets



\-> difference

&#x09;-> <set\_1> - <set\_2>

&#x09;-> elements of set\_1 not in set\_2



\-> symmetric difference

&#x09;-> <set\_1> ^ <set\_2>

&#x09;-> all elements from both the sets except common elements





\-> in and not in operation
