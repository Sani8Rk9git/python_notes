**SET FUNCTIONS**



\-> len(<set>)

\-> sum(<set>)

\-> min(<set>)

\-> max(<set>)

\-> sorted(<set> , reverse = True/False)





\-> <set1>.union(<set2>)

&#x09;-> returns a new set

&#x09;-> originals remain the same



\-> <set1>.update(<set2)

&#x09;-> the result after the union is stored in set1

&#x09;-> set2 remains the same





\-> <set1>.intersection(<set2>)

&#x09;-> returns a new set

&#x09;-> originals remain the same



\-> <set1>.intersection\_update(<set2)

&#x09;-> the result after the intersection is stored in set1





\-> difference()

\-> difference\_update()



\-> symmetric\_difference()

\-> symmetric\_difference\_update()



\-> <set1>.isdisjoint(<set2>)



\-> <set1>.issubset(<set2>)



\-> <set1>.issuperset(<set2>)



\-> set = set1.copy()
