**TUPLE OPERATIONS**



\-> joining tuples

&#x09;-> + operator is used for concatenation

&#x09;-> both the operands must be of tuple types



\-> repeating tuples

&#x09;-> \* operator is used to repeat the elements of a tuple a specific number of times



\-> slicing the tuple

&#x09;-> just like list

&#x09;-> \[start : stop]

&#x09;	-> stop not included

&#x09;-> \[start : stop : step]





\-> comparison operators can be used for tuples

&#x09;-> individual elements of the tuples are compared



\-> Packing and unpacking tuples

&#x09;-> creating a tuple from a set of values is packing

&#x09;-> creating individual values from a tuple's elements is called unpacking

&#x09;	-> var1 , var2 , var3 , ... = <tuple>

&#x09;	-> number of variables on the left side must match the number of elements of tuple



\-> del <tuple\_name>

&#x09;-> used to delete elements and objects 





\-> we can indirectly modify the tuple values using

&#x09;-> method 1

&#x09;	-> unpack the tuple

&#x09;	-> change the variable values 

&#x09;	-> repack the tuple 

&#x09;-> method 2

&#x09;	-> convert tuple to list using list()

&#x09;	-> change the list elements

&#x09;	-> create the tuple with the list using tuple()
