**TUPLE FUNCTIONS**



\-> len(<tuple>)

&#x09;-> returns the count of the elements in the tuple



\-> max(<tuple>)

&#x09;-> returns the element from the tuple having the maximum value

&#x09;-> the provided tuple must contain values of the same type

&#x09;-> if values are not of the same type then python returns an error



\-> min(<tuple>)

&#x09;-> return the element from the tuple having the minimum value

&#x09;-> the element must be of the same type



\-> sum(<tuple>)

&#x09;-> returns the sum of the elements of the tuple

&#x09;-> tuple must have numeric elements



\-> <tuple\_name>.index(<item>)

&#x09;-> returns the index of the existing item provided(index of the first occurrence)

&#x09;-> if the item does not exist, it returns an error



\-> <tuple\_name>.count(<object>)

&#x09;-> return the count of the object



\-> sorted(<tuple> , reverse = False/True)

&#x09;-> returns a sorted list not tuple with sorted element in it

&#x09;-> always output the result of list type

&#x09;-> reverse = False or missing --> ascending

&#x09;-> reverse = True --> descending
