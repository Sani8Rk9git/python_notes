**CREATING TUPLES**



\-> put the items in parentheses ()

\-> separate the items by commas





\-> Empty tuple

&#x09;-> <var\_name> = ()

&#x09;-> <var\_name> = tuple()





\-> Single element tuple

&#x09;-> <var\_name> = value,

&#x09;-> <var\_name> = (value,)





\-> long tuples

&#x09;-> <var\_name> = (val1, val2, val3 ...)





\-> can create tuples from other sequences

&#x09;-> <var\_name> = tuple(<sequence>)

&#x09;-> sequence can be string or list

&#x09;-> individual elements of the tuple are created from the individual elements of

&#x09;	the passed sequence.
