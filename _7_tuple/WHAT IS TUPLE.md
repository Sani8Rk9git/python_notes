**WHAT IS TUPLE**



\-> Tuples are sequences

\-> used to store values of any type

\-> tuples are **immutable** (cannot change elements of a tuple in place)

&#x09;-> existing tuple cannot be changed

\-> python create a fresh tuple if changes to an element of the tuple is made

\-> tuple is a standard datatype of python

\-> tuples are depicted by round brackets

\-> tuples are ordered

\-> tuple can be considered as immutable list
