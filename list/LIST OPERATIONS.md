**LIST OPERATIONS**



\-> The + operator can be used to join two lists

&#x09;-> require both the operands as lists



\-> <list> += <sequence>

&#x09;-> this only works if the right side has a sequence





\-> \* operator is used to replicate a list specified number of times

&#x09;-> require a list and an integer

&#x09;-> the elements of the list are repeated in whole
