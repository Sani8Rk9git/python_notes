**CREATING LIST**



**Creating Lists**

\-> Use square bracket to indicate the start and end of the list and separate the items by commas.

\-> A list can have another list as its element. This is called nested list



\-> <variable\_name> = list(<sequence>) can be used to create list from the sequence

&#x09;-> The sequence can be any kind of sequence object.

&#x09;-> Python creates the individual elements of the list from the individual elements of 

&#x09;	the passed sequence.

&#x09;-> Because the list() constructor will only take iterables (or nothing) as arguments,

&#x09;	objects that are not iterable will raise a TypeError.





\-> If another list is passed, the list function makes a copy

\-> To input list use the eval(input()) method



\-> For readability, line breaks can be used when there are many elements or nested data structures within a list
