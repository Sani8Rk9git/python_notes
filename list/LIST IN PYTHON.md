**LIST IN PYTHON**



\-> Python list are containers that are used to store a list of values **of any type.**

&#x09;-> lists can hold reference to any (or multiple) data type(s) - including other

&#x09;	lists

\-> Lists are implemented as dynamic arrays

\-> They are mutable (we can change the elements of a list in place)

\-> Python will not create a new list when we make changes to an element of a list.

\-> The memory address of a list will not change even after changing its element.

\-> List is a type of sequence in python.

\-> It is a standard datatype



\-> empty list \[]

&#x09;-> it is equivalent to 0 or ''

&#x09;-> It has the truth value as false

\-> <variable\_name> = list() will also generate an empty list
