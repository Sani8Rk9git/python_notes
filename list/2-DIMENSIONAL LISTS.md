**2-DIMENSIONAL LISTS**

&#x09;-> It is a list having all its elements as lists of same shape

&#x09;-> It is a list of lists

&#x09;-> Same shape means all are singular lists (non-nested)





Regular 2-d lists

&#x09;-> these are 2D lists with following properties:

&#x09;	-> all elements have same shape (same dimension and length)

&#x09;	-> the len(<list\_name>) tells the number of rows

&#x09;	-> len(<list\_name>\[n]) tell the number of columns



Ragged list (irregular 2-d lists)

&#x09;-> it is a 2-d list with list elements of different shapes





\-> Nested list

&#x09;-> a list that has one or more lists as its elements
