**ACCESSING LIST**



**Accessing Lists**



\-> List also index their individual elements

&#x09;-> forward indexing start from 0 to lenght-1

&#x09;-> backward indexing -length to -1



\-> List store a reference(memory address) at each index of the individual elements

\-> <list\_name>\[index]

\-> when negative index is passed, then python add the length of the list to the negative index to get its forward index and then display the value



\-> len(list\_name) will return the number of elements in the list



\-> <list\_name>\[<start> : <stop> : <step>] returns a new list, containing the objects at indexes between <start> and <stop>-1

&#x09;-> by default the step value is 1

&#x09;-> if no start and stop are given, slice will start from 0 and stop = length + 1

\-> in and not in can be used





\-> <list\_name>\[index] = element

\-> it can be used to change the individual element of the list
