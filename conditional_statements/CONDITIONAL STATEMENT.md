**CONDITIONAL STATEMENT**



\-> the execution of the statements depend on the condition-test

\-> if, elif, else statements are used to control the flow of execution and make decisions in the program.

\-> Conditional statements use expressions that must resolve to True or False -- either by returning a bool directly, or by evaluating "truthy" or "falsy".

\-> Conditionals can also be nested.







1. if statement

&#x09;-> tests a condition

&#x09;-> if the condition evaluates to True ----> carries out some 

&#x09;	instruction

&#x09;-> condition evaluates to False ----> does nothing

&#x09;-> if multiple if are written then each if conditions are checked.

&#x09;-> Syntax :

&#x09;	if condition:

&#x20;   			#statement





2\. if - else statement

&#x09;-> condition is checked

&#x09;-> if true ----> if block executes

&#x09;-> false ----> else block executes

&#x09;-> Syntax:

&#x09;	if condition:

&#x20;  			#statement

&#x09;	else:

&#x20;  			#statement





3\. if - elif - else statement



&#x09;-> Syntax:

&#x09;	if condition:

&#x20; 			#

&#x09;	elif condition:

&#x20; 			#

&#x09;	else:

&#x20; 			#



\-> t is possible to write single-line conditional expressions. 

&#x09;-> These take the form of <value if True> if <conditional test> else <value if False>



\-> In Python, any object can be tested for truth value, and can therefore be used with a conditional, comparison, or boolean operation. 

&#x09;-> Objects that are evaluated in this fashion are considered "truthy" or "falsy", and used in a boolean context.
