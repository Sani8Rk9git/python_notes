**COMPARISON OPERATORS**



\-> A comparison operator in Python (also called a Python relational operator), looks at the values of two operands and returns a boolean True or False if the comparison condition is or is not met.



\-> Most commom python comparison operators:

&#x09;-> greater than >

&#x09;-> less than <

&#x09;-> equal to ==

&#x09;-> greater than or equal to >=

&#x09;-> less than or equal to <=

&#x09;-> not equal to !=

&#x09;-> identity is

&#x09;-> negated identity is not 

&#x09;-> containment test in

&#x09;-> negated containment test not in

&#x09;-> They all have the same priority (which is higher than that of Boolean operations, but lower than that of arithmetic or bitwise operations).



\-> Any ordered comparison of a number to a NaN (not a number) type is False



\-> Comparison operators can be chained arbitrarily. 

&#x09;-> Note that the evaluation of an expression takes place from left to right. 

&#x09;-> For example, x < y <= z is equivalent to x < y and y <= z, except that y is evaluated only once. 

&#x09;-> In both cases, z is not evaluated at all when x < y is found to be False.

&#x09;	-> often called short-circuit evaluation
