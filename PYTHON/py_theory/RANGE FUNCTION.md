**RANGE FUNCTION**



* range() function is used with the for loop
* It generates a list which is a special sequence type



Common syntax : 



range(<lower limit> , <upper limit>)  both should be integers



* it will produce a list having numbers from lower limit to upper limit - 1
* upper limit is not included
* the default step value will be +1



range(<lower limit> , <upper limit> , <step value>)



* all should be integers



range(<number>)



* it creates a list from 0 to number - 1



* The in operator is used to check if a value is present in a sequence and returns True and False accordingly.
