**LOOPING**



* To carry out repetitive tasks, python provides following iterative/looping statements:



&#x20;1. Conditional loop while (condition based loop)

&#x20;2. Counting loop for (loop for a given number of times)



For loop



* It is used to process the items of any sequence one by one.



Syntax : 



for <variable> in <sequence>:

&#x20;   #statement to repeat



* the loop variable is assigned the value of the sequence one by one and for each assigned value the body of the loop will be executed.





for <variable> in range():

&#x20;   #statements







* We do not have to pre-define the loop variable for the for loop.











while loop





* It is a conditional loop 
* It will repeat the instructions within itself as long as the condition remains True.



Syntax :



while logical\_condition:

&#x20;   #loop\_body



* The variable used in the condition of the while loop must have some value before entering into while loop.
