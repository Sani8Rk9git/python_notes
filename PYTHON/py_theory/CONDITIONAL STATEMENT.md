**CONDITIONAL STATEMENT**



* the execution of the statements depend on the condition-test



1. if statement



* tests a condition
* if the condition evaluates to True ----> carries out some instruction
* condition evaluates to False ----> does nothing
* if multiple if are written then each if condition are checked.



Syntax : 



if condition:

&#x20;   #statement



2\. if - else statement



* condition is checked
* if true ----> if block executes
* false ----> else block executes





Syntax:



if condition:

&#x20;  #statement

else:

&#x20;  #statement





3\. if - elif - else statement



Syntax:



if condition:

&#x20; #

elif condition:

&#x20; #



else:

&#x20; #
