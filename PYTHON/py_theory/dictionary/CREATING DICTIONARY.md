**CREATING DICTIONARY**



Creating dictionary



* write the key:value pairs of the dictionary, separated by comma, enclosed in the {} brackets



* 2 ways to create empty dictionary :



1. <variable\_name> = {}

2\. <variable\_name> = dict()



* To add a key : value pair in the dictionary one at a time :

<dictionary\_name>\[key] = value

\-> if the key already exist then its value gets changed



* <variable\_name> = dict(key1=value1 , key2 = value2 .....)
