**DICTIONARY - intro**



* It is a type of collection in python (Bunch of values in a single variable)
* It is a built-in python datatype
* They are also called associative arrays/mappings/hashes
* It has a **key** and **a value of that key**
* It **does not** have an index associated with each data-item
* It is a container that associate keys to values



* It is an **unordered set**

**->** it is an unordered set of key : value pairs

\-> Values can contain reference to any type of object

\-> No order or position of the key : value pairs as no index



* It is not a sequence

\-> Since it is unordered so it is not a sequence







* They are mutable

\-> (we can change the value of a certain key in place by using the assignment statement)

<dictionary\_name>\[key] = value



* unordered collections with elements in the form of a key:value pair that associate keys to values(it is not a sequence with index of ordinal numbers )



* **keys of the dictionary must be of immutable type** (numbers, strings)
* a tuple can be key only if it contains immutable elements
* **Each key within the dictionary must be unique as** keys are used to identify values in the dictionary, there cannot be duplicate keys in the dictionary
* Values can be of any type and type can be mixed within one dictionary
