**COMMENTS**



* any line that begin with the **#** symbol is a comment in python.
* These lines are ignored by python
* Only for code readability



* **Inline** comments are written between the lines of the python code.
* Full line comments are whole lines that are comments.





&#x20;Multi-line comments 



* These multi-line comments are also known as docstring that are used for documentation.
* 2 ways for writing these :

&#x20;      1. Add # symbol in the beginning of every line



&#x20;      2. Type comment as a triple quoted multi-line string (triple double quotes or single 

&#x20;                                                                                     quotes)
