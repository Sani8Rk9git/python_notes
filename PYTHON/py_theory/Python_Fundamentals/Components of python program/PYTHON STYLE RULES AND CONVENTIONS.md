**PYTHON STYLE RULES AND CONVENTIONS**



* Python does not use any symbol to terminate a statement 
* When we end a code-line by pressing enter, the statement is considered terminated by default



* Indentations are used to represent the blocks of code
* Indentation is enforced with **4 spaces (not tabs)** per indentation level



* We can combine more than one statements in one line using the semi-colon ;



* Python is **case-sensitive**
