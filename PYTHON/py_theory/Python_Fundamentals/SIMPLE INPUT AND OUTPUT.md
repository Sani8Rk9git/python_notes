**SIMPLE INPUT AND OUTPUT**



* To get input from user , built-in function **input()** is used



Syntax :



&#x20;variable\_to\_hold\_value = input(<prompt to be displayed>)



* Type the value in front of the displayed prompt and it will get assigned to the variable.



* input() will always return the value of **string type. It means that whatever value you enter through input() function is treated as string.**



* To read numbers through the input() function :



&#x20;<variable\_name> = int(input(<prompt string>)) convert the read value into int type

&#x20;<variable\_name> = float(input(<prompt string>)) convert the read value into float type





* While entering numeric values through input() along with int() / float() , make sure to enter values that are convertible to the target type.





* print() function is used for the outputs
