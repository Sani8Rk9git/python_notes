**ACCESSING LIST**



**Accessing Lists**



* List also index their individual elements
* forward indexing start from 0 to lenght-1
* backward indexing -length to -1



* List store a reference at each index of the individual elements
* <list\_name>\[index]
* when negative index is passed, then python add the length of the list to the negative index to get its forward index and then display the value



* len(list\_name) will return the number of elements in the list
* <list\_name>\[i:j] returns a new list, containing the objects at indexes between i and j-1
* in and not in can be used





* <list\_name>\[index] = element
* it can be used to change the individual element of the list
