**CONTINUE statement**



\-> It is a jump statement to skip over a part of the code

\-> continue forces the next iteration of the loop to take place, skipping any code in between





break statement

&#x09;-> The break keyword can be used to stop the iteration and "break out" of the innermost enclosing loop





else statement

&#x09;-> The loop else clause is unique to Python and can be used for "wrap up" or "concluding" actions when iteration has been exhausted.

&#x09;-> Statements following the else keyword will not execute if iteration terminates via 

&#x09;	break
